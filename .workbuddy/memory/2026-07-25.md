# 2026-07-25 工作日志

## Atlas PM WebApp — 阿里云上云部署

### 任务
用户要将 pm-webapp.html 部署到阿里云 ECS 服务器,让任何电脑/浏览器都能通过公网 IP 访问。

### 完成内容
1. **部署脚本** `deploy-to-aliyun.sh` — 一键部署: 自动安装 Nginx, 创建目录, 配置 Nginx, 开放防火墙, 启动服务, 支持 --ssl 参数配置 HTTPS
2. **部署指南** `DEPLOY-GUIDE.md` — 完整图文指南: 一键脚本部署 / 手动分步部署 / HTTPS 配置 / 常见问题排查
3. **Nginx 配置** `nginx-atlas-pm.conf` — 独立 Nginx 配置文件, 含 gzip 压缩, 静态资源缓存, 安全响应头
4. **部署目录** `deploy/index.html` — pm-webapp.html 副本, 用于 CloudStudio 部署

### 技术方案
- 纯前端单文件应用, Nginx 直接提供静态文件服务, 无需数据库/后端
- SCP 上传文件 + SSH 运行脚本即可完成部署
- 阿里云安全组需开放 80 端口 (HTTP) 和 443 端口 (HTTPS)

### CloudStudio 部署
- 尝试 CloudStudio 部署 3 次均失败 (fetch failed), 网络问题
- 本地服务器 http://localhost:3840 可正常预览

### 关键提醒
- 数据存储在浏览器 localStorage, 不同设备数据独立 (纯前端应用特性)
- 后续如需多用户共享数据, 需升级为后端+数据库方案
