## Bug Fix — Login Page Language Switch Not Working

**Root cause**: `exportPDF()` function contained `</script>` inside a template literal string. The HTML parser closes the outer `<script>` tag at the first `</script>` it encounters, even inside JS strings. This caused the entire JS block to fail parsing (SyntaxError), making ALL functions undefined — including `setLang`, `doLogin`, and `init`.

**Fix**: Split `</script>` into string concatenation `'</scr' + 'ipt>'` to prevent premature tag closure. Also removed a stray backtick that was left over from the original template literal.

**Lesson**: Never put literal `</script>` inside a `<script>` block — always escape it as `<\/script>` or split it via string concatenation.

## Complete Rewrite — Fix Chinese i18n Not Working on Main Interface

**Root cause**: The original file had an i18n system (`I18N` dictionary + `applyTranslations()`) but the HTML for Dashboard, Kanban, Team, Reports, Settings pages had most text hardcoded in English WITHOUT `data-i18n` attributes. So `applyTranslations()` only affected the login page and a few elements, leaving the main app interface in English even when `currentLang === 'zh'`.

**Fix**: Complete rewrite of `pm-webapp.html` (1880 lines):
- Added `data-i18n` attributes to ALL visible text elements across every page
- Extended I18N dictionary to ~200+ keys per language (en/zh)
- All dynamic data arrays use `name`/`nameZh` dual fields with helper functions (`memberName()`, `projectName()`, etc.) that switch based on `currentLang`
- `renderAll()` calls `renderDashboard()` + `renderKanban()` + `renderTeam()` + `renderReports()` to re-render all dynamic content on language change
- `setLang()` chain: `currentLang = lang` → `localStorage.setItem` → `applyTranslations()` → `setLangButtonState()` → `renderAll()`
- `applyTranslations()` detects child elements to avoid overwriting SVG icons inside nav buttons
- Plan modal with 5-step phase stepper (planning → design → development → testing → deployment)
- Export functions: PDF (print window), Word (Blob .doc), PNG (html2canvas)
- Default language: `zh` (Chinese)

**Key pattern for safe text replacement**:
```javascript
// Check if element has element children (like SVG icons) before setting textContent
var hasElementChild = false;
for (var j = 0; j < el.childNodes.length; j++) {
  if (el.childNodes[j].nodeType === 1) { hasElementChild = true; break; }
}
if (!hasElementChild) { el.textContent = t(key); }
```
